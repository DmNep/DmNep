**Сейчас в работе**

- [**x_connector**](https://github.com/DmNep/x_connector): внеполосная консоль Windows → Linux по аудиокабелю. Команды идут звуком, обратно приходит сетка терминала. Нужна, чтобы починить сеть на сервере, когда сети нет. Python, только stdlib.

- [**OpenSXM**](https://github.com/DmNep/OpenSXM): открытая плата на пять бюджетных V100 SXM2 с NVLink к соседней плате. Такие платы можно объединять между собой по скоростному каналу NvLink строя цепочку под большие локальные модели терабайтного класса. Расчет 25-30 ток/с при примерно 5 агентах в паралельной работе. Пока только план и макеты.
